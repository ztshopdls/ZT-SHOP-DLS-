ZT SHOP DLS - Front-end Website
================================

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all 3 files in the same folder.
2. Open index.html in Chrome to preview the website.
3. Change prices/packages in script.js.
4. Replace the support/contact placeholders in index.html.

Important:
- The checkout is a front-end demo only.
- bKash/Nagad buttons do not process real payments.
- For a real shop, connect an authorized payment gateway and a secure backend/order database.
